# SeaVolt (PASES)

Portable Aluminum-Seawater Energy System — an off-grid device that converts waste
aluminum and seawater into **fresh water, hydrogen fuel, and usable heat/electricity**.

## Research summary

PASES uses an exothermic aluminum-water reaction
(`2Al + 6H₂O → 2Al(OH)₃ + 3H₂ + heat`) to drive reverse-osmosis desalination and a
fuel cell, delivering dual outputs (water + hydrogen) from scrap aluminum and
seawater with no grid connection. Full details in
[docs/PASES_Research.md](docs/PASES_Research.md).
